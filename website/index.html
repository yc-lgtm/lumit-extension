Quick Setup

  1. Install Lumit desktop app and start the controller.
  2. Install Lumit VS Code extension and confirm bridge status.
  3. Add provider keys in .env for model and web services.
ANTHROPIC_API_KEY=
OPENAI_API_KEY=
GEMINI_API_KEY=
SERPER_API_KEY=
GOOGLE_CREDENTIALS_PATH=./credentials/google-credentials.json
